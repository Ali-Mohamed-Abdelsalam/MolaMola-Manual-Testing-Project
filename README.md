# Mola Mola Diving Center – Manual Testing Project

### Project Overview

This repository documents the manual QA testing performed on **Mola Mola Diving Center**, a diving and snorkeling website offering trips, courses, and activities in Muscat, Oman.

The project focused on evaluating the website's core functionality and user experience through structured test case design, manual execution, and bug reporting.

---

## 3. Bug Reporting & Key Findings

The testing process recorded **12 failed test cases**, documented separately in the Bug Report.

The following table summarizes the main findings:

| Area | Failed Cases | Reported Finding |
|---|---:|---|
| Navigation & Trip Content | 4 | Page content obscured by images |
| Contact Information | 2 | Incorrect map and address destinations |
| Booking Form | 2 | Input validation and large-value handling issues |
| Private Trip Pricing | 1 | Displayed total does not change with the people count |
| Course & Package Booking | 2 | Selected course or package is not preserved during booking |
| Dive Trips Page | 1 | Reported 404 response for the Dive Trips URL |

**Note:** The private-trip pricing behavior and Dive Trips URL require confirmation of the intended requirements before being classified as confirmed defects. Some reported failures may share the same root cause.
